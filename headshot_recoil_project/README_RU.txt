HEADSHOT RECOIL — Android project
=================================
Внутри: дизайн приложения, профили 50/60/80/99%, переключатели рекомендаций для телефона и кнопка Telegram.

ВАЖНО: это исходный Android Studio проект, а не готовый APK. В текущей среде нет Android SDK и Gradle, поэтому APK здесь собрать не удалось.
Как собрать APK:
1. Установите Android Studio на компьютер.
2. Откройте папку HeadshotRecoil как проект.
3. Дождитесь синхронизации Gradle и установки нужных Android SDK компонентов.
4. Выберите Build > Build APK(s).
5. APK обычно появится в app/build/outputs/apk/debug/app-debug.apk.

Приложение работает офлайн, кроме открытия Telegram-ссылки. Оно не изменяет файлы/настройки Free Fire автоматически и не обещает реального усиления FPS. Профили — выбор внутри приложения.
